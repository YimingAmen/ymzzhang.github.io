1. 为什么要学习 HTML5？

HTML5 不只是标签升级，它定义了现代 Web 页面结构和能力边界。掌握它，意味着你可以写出更标准、更可维护，也更易于被搜索引擎和辅助技术理解的页面。

2. 核心新特性速览

  • 语义化标签：页面结构更清晰，便于团队协作。
  • 增强表单：如 email、date、range 类型，减少手写校验逻辑。
  • Canvas 与 SVG：支持动态绘图与可视化场景。
  • Web API：地理定位、拖拽、历史记录等浏览器能力更加标准化。

3. 学习建议

  • 先掌握语义化和可访问性，再进入动画、性能优化等进阶内容。
  • 尽量使用现代浏览器开发工具，实时查看 DOM、性能与网络请求。
  • 建立“结构（HTML）- 表现（CSS）- 行为（JS）”的分层习惯。
